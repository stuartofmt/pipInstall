# pipInstall - pipInstall branch

> [!WARNING]
> **pipInstall (Version 1) is no longer maintained.** It receives no fixes or updates. Use [pipInstall2](https://github.com/stuartofmt/pipInstall#versions) instead.

This branch is the code for pipInstall (Version 1). It does not work on operating systems that require Python packages to be installed in a virtual environment (venv), e.g. Debian Bookworm or later.

The documentation is on the master branch:

- [pipInstall (Version 1)](https://github.com/stuartofmt/pipInstall/blob/master/docs/1/README.md)
- [All versions](https://github.com/stuartofmt/pipInstall#versions)
